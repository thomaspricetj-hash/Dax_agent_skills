# DAX Agent Skill

Bionic Skill that integrates Weaveformer DAX design.

## Install
Copy this folder to `C:\Users\thoma\.lmstudio\skills\dax-agent\`

## Usage
* `dax chat <prompt>` – chat with Muse-Glimmer + DAX memory
* `dax train <dataset.csv>` – train specialists
* `dax build` – build project and log errors to Journal
* `dax workspace` – list workspace files
* `dax open <path>` – open file in side editor

Memory is persisted in DAX checkpoints and Journal/Diary.
